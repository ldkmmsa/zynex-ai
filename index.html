Chat met een lokaal AI-model via Ollama. Je gesprekken worden op je eigen pc verwerkt; dit is geen cloudchat of web-AI.

Download Zynex AI voor Windows

Zynex AI.exe · 144 KB · Geen installer

Zo start je

  1. Installeer Ollama voor Windows.
  2. Open PowerShell en download een lokaal model, bijvoorbeeld ollama pull qwen2.5:7b.
  3. Start Ollama en open daarna Zynex AI.exe.

Ollama en het AI-model moet je zelf installeren; ze zijn niet inbegrepen. Internet is nodig voor die downloads. Chatten met een geinstalleerd lokaal model blijft lokaal.

Goed om te weten

Zynex AI is niet digitaal ondertekend. Windows kan daarom een beveiligingswaarschuwing tonen of het starten blokkeren. Ga alleen verder als je de herkomst vertrouwt. Beheerbeleid op een werk- of schoolcomputer kan alleen door de beheerder worden aangepast.

AI-modellen kunnen fouten maken. Controleer belangrijke antwoorden zelf.
